# End-to-End Pizza Sales Analysis using Excel + SQL + Power BI
This project analyzes a pizza restaurant’s historical sales data to uncover key business insights using Excel, SQL queries, and Power BI tools. The goal is to evaluate overall performance, understand customer ordering behavior, and identify product trends that influence revenue.
The dataset used in this project is the *Pizza Sales Dataset* from Kaggle.

🔗 Source: https://www.kaggle.com/datasets/nextmillionaire/pizza-sales-dataset

### Tools Used:
- Excel: Pivot Tables and Interactive dashboard creation
- SQL queries: Data extraction, aggregation, trend analysis, and KPI calculations
- Power BI: Data modeling, visual dashboards, interactive charts for trends, category breakdowns, and top selling Pizza

### Key Business Questions Answered:
- Which pizza category generates the highest sales?
- Which pizza size receives the most customer orders, and which size performs the least?
- What are the top 5 best-selling pizzas, and which are the bottom 5 lowest-selling pizzas?
- Which month and quarter recorded the highest sales performance?
- During which time of day do sales peak?

### Key Insights:
- Total Revenue: 817K
- Total Orders: 21K
- Total Pizza Sold (Quantity): 50K
- Average Order Value (AOV): 38.31
